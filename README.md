Permission to Occupy (PTO) Management System



Project Description



The Permission to Occupy (PTO) Management System is a digital solution designed to help municipal officials capture, manage, monitor and track PTO records.



The system aims to improve the current process, which relies on Excel spreadsheets and manual processes.



Technologies Used



\- Flutter

\- Dart

\- C#

\- ASP.NET Core MVC

\- Supabase

\- GitHub



    Project Structure



   Flutter Mobile App

The Flutter application provides mobile access to the PTO management system.



    ASP.NET MVC Web Application

The C# ASP.NET Core MVC application provides the web-based system for authorised municipal officials.



   Supabase

Supabase is used for centralised database storage and management.



  Documentation

Project documentation such as the SRS, feasibility study, risk register, diagrams and stakeholder evidence will be stored in the documentation section of the repository.



  Main Features



\- User Authentication

\- Beneficiary Management

\- Site Management

\- PTO Creation

\- PTO Status Management

\- PTO Expiry Monitoring

\- PTO Renewal

\- PTO De-registration

\- Search

\- Filtering

\- Dashboard

\- Record History

\- Data Security



   Project Scope



The project focuses on digitising and centralising the PTO management process.



The initial prototype does not include the complete Human Settlements process or direct integration with all existing government systems.
